# Student Manager

## 1. Giới thiệu
Student Manager là chương trình quản lý sinh viên đơn giản được xây dựng bằng Python. Dự án hỗ trợ lưu trữ và hiển thị thông tin sinh viên.

## 2. Chức năng chính
- Khởi tạo đối tượng sinh viên.
- Lưu thông tin mã sinh viên, họ tên, tuổi và điểm.
- Hiển thị danh sách sinh viên.
- Chuyển thông tin sinh viên sang dạng Dictionary.

## 3. Công nghệ sử dụng
- Ngôn ngữ: Python 3
- Quản lý mã nguồn: Git
- Nền tảng lưu trữ: GitHub

## 4. Cấu trúc dự án
```text
StudentManager/
├── src/
│   ├── main.py
│   └── student.py
├── README.md
└── .gitignore
```

## 5. Phiên bản
**Version 1.0.0** — Phát triển bởi Nhóm A & Nhóm B.

## 6. Cách chạy chương trình
Mở Terminal tại thư mục dự án và chạy:

```bash
python src/main.py
```
